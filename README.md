# SP3 Atlas

Archive and development repository for **SP3 Atlas — Daytona SP3 Public Registry**.

## Versions

- `sp3_atlas.html` — original archived version
- `sp3_atlas_v2.html` — second archived version

Both files are self-contained HTML snapshots and embed substantial page assets directly in the document, so the repository is intentionally simple.

## Workflow

Keep archived versions immutable. For future work, create a new numbered file or branch rather than overwriting an old snapshot. This preserves the visual/data evolution of the registry.
