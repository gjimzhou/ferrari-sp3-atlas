# Ferrari Daytona SP3 Atlas

Public-source registry and visual atlas for the Ferrari Daytona SP3.

## Live website

Once GitHub Pages is enabled for `main` / `(root)`, the site will be available at:

**https://gjimzhou.github.io/ferrari-sp3-atlas/**

The website entry point is `index.html`.

## Repository structure

- `index.html` — live GitHub Pages site
- `sp3_atlas.html` — archived original snapshot
- `sp3_atlas_v2.html` — archived v2 snapshot
- `PUBLIC_SOURCES.md` — public links, image sources, auction/dealer references

## Research model

The atlas is built around public-source evidence: Ferrari material, auction catalogues, dealer listings, established automotive press, public event coverage, and lower-confidence community evidence when clearly labeled.

Public images should remain attributed to their original publishers and, where practical, be linked to the original source page rather than re-hosted without permission.

## Privacy boundary

The project may catalog public facts about cars: configuration, publicly published chassis/VIN information, auction history, public event appearances, and public source URLs. It should not attempt to uncover non-public owner identities, home addresses, personal contact information, private travel patterns, or other private details.
