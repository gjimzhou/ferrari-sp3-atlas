# 如何使用 SP3 Atlas / Reader guide

[资料库](https://gjimzhou.github.io/ferrari-sp3-atlas/) · [文档目录](README.md)

| 想看什么 | 网站入口 | 阅读边界 |
| --- | --- | --- |
| 一辆车的配置、照片和公开证据 | [车辆档案](https://gjimzhou.github.io/ferrari-sp3-atlas/#registry) | 点击详情，逐项看来源；未知字段保持未知 |
| 公开报道中的人物与收藏关系 | [公开车主](https://gjimzhou.github.io/ferrari-sp3-atlas/#owners) | 历史关系不代表当前持有人 |
| 成交、估价与挂牌 | [拍卖与挂牌](https://gjimzhou.github.io/ferrari-sp3-atlas/#market) | 保留原币种与来源时点，不混用报价与成交 |
| 继续调查未确认车辆 | [来源索引](https://gjimzhou.github.io/ferrari-sp3-atlas/#sourceIndex) | 来源页面不是唯一实车身份证明 |
| 地点分布与统计口径 | [国家分布](https://gjimzhou.github.io/ferrari-sp3-atlas/#countries) | 地点／旗标不是配额或国籍 |
| 理解证据、去重和版权 | [资料与方法](https://gjimzhou.github.io/ferrari-sp3-atlas/#methods) | 记录数、来源数与实车数不能相加 |

Switch 中文 / EN in the website header. Language changes presentation, not evidence. Use the search field for names, VINs or configurations; an empty result is not proof that a car does not exist. Each record links to its supporting public sources.
